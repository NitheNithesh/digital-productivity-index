# Digital Productivity Index (DPI)

## Project Overview
This project aims to develop and preliminarily evaluate a Digital
Productivity Index (DPI) for measuring digital work habits across
work environments.

## Objectives
- Identify key dimensions of digital work habits.
- Develop a structured questionnaire for working professionals.
- Calculate dimension scores and an overall DPI score.
- Examine relationships between digital work habits and
  self-rated productivity.
- Provide practical feedback based on respondents' scores.

## Technology Stack
- Python
- Streamlit
- Pandas and NumPy
- SciPy and Statsmodels
- Google Sheets for response storage, subject to secure configuration

## Research Design
Quantitative, descriptive, cross-sectional questionnaire survey.

## Data Privacy
The application is intended to collect anonymous questionnaire
responses. Personal identifiers will not be requested.
Response storage and access controls must be tested before
the survey is shared with participants.
